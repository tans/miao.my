# 更新日志

## v0.2.0
- date: 2026-10-11
- tags: 已打包
- links: Release | https://github.com/tans/miao/releases/tag/v0.2.0 | Commit | https://github.com/tans/miao/compare/v0.0.1...v0.2.0

- **导出与查找更方便。** 可以把一张应用数据表导出为 CSV；跨所有可访问应用和表搜索记录；用稳定链接分享单条记录。
- **通知更及时。** 可以筛选并全部标记通知为已读；后台任务支持按间隔、每月和 cron 触发；工作区通知可通过邮件、企业微信、钉钉和飞书送达。
- **小助手与界面。** 应用设置更清晰；界面语言保持中文和英文两种。
- **稳定性。** 修复认证端点限速、分页越界查询、后台工作线程崩溃隔离和管理员授权等问题。

## 2026-10-03 – 10-06

- **受控 json-render 运行时。** 后端 harness 与 json-render 渲染运行时上线，草稿通过 harness 组合与校验。
- **业务动作与工作流。** 通用事务性业务动作、输入声明校验、工作流状态机、受限外部连接器。
- 后台任务接入共享 Runtime；发布只读公开应用页；Jev 决策改用固定版本评估器。
- 修复：附件/外发迁移、自动化重试、AI 配额事务内预留、账号注销事务化等一大批稳定性问题。
