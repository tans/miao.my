# 更新日志

## v0.0.1
- date: 2026-10-10
- tags: 已打包
- links: Release | https://github.com/tans/miao/releases/tag/v0.0.1 | Commit | https://github.com/tans/miao/commit/aca7ce5

- **首个打包版本。**二进制包可从 GitHub Release 下载，安装无需 Go 工具链和 npm 依赖。SHA-256 以 Release 附件中的同名 `.sha256` 为准。
- 本地 API 测试套件独立到 miao-test 仓库。
- 修复：拒绝旧版 LLM 配置重置；恢复受控 LLM 决策提案。
- 界面：工作区侧栏更紧凑；小助手支持显示/隐藏切换。
- 业务配置视图改为只读，精简只读设置加载。

## 2026-10-03 – 10-06

- **受控 json-render 运行时。**后端 harness 与 json-render 渲染运行时上线，草稿通过 harness 组合与校验。
- **业务动作与工作流。**通用事务性业务动作、输入声明校验、工作流状态机、受限外部连接器。
