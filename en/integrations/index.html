INTEGRATION DIRECTORY · CAPABILITIES, NOT LOGOS

Integrations and boundaries

A clear distinction between available capabilities, controlled features, and planned connectors. MIAO prioritizes least privilege, reproducibility, and self-hosting. An unlisted service is not a compatibility claim.

Anonymous read-only

Security boundaries

  • Credentials and model keys belong on the MIAO server, never in browser code, public specs, or page URLs.
  • External reads have request budgets, response-size and timeout limits, and destination-address checks to reduce SSRF risk. Self-hosters should also restrict server egress.
  • Collection writes target internal MIAO data; they are not writes to third-party services. Review run receipts and business audit records.
