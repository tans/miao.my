CHANGELOG

更新日志

记录 MIAO 应用的版本更新：新功能、改进与修复。MIAO 以发布日期标识版本，可随时在 GitHub 仓库查看全部变更。

v0.0.1

2026-10-10当前版本Release ↗
  • 首个打包版本。版本号定为 0.0.1，二进制包可从 GitHub Release 下载，安装无需 Go 工具链和 npm 依赖。
  • 本地 API 测试套件独立到 miao-test 仓库。
  • 修复：拒绝旧版 LLM 配置重置；恢复受控 LLM 决策提案。
  • 界面：工作区侧栏更紧凑；小助手支持显示/隐藏切换。
  • 业务配置视图改为只读，精简只读设置加载。

2026-10-09

构建 3388d67
  • 应用图标与版本切换。新增应用图标和本地图标选择器；应用运行时工具栏可直接切换版本。
  • 自托管 daisyUI 与 Tailwind 浏览器资源，减少前端启动资源传输。
  • 发布对话式 UI 草稿无需二次确认；移除应用运行时下的草稿与版本历史区块。
  • 修复：表单去重并持久化运行指标、应用设置渲染、工作区选择器越界、助手加载与模型错误提示、清理失败的助手重试。
  • 禁用旧版 LLM Agent 流程；Jev 评估全部改用 Typesafe。

2026-10-08

  • 版本发布与 SSE 流式更新。支持发布应用变更并切换版本；助手和应用运行时更新改为 SSE 流式推送。
  • Agent 运行接入后台任务；平台标题可配置。
  • 修复：删除应用时保留数据表、无需登录闪动地恢复登录态、遗留数据目录归一到初始 schema、运行时包元数据归档。

2026-10-07

大版本日
  • 工作台全面成型。小助手固定为第三栏深色终端风格停靠列；工作区切换器改为下拉菜单；图标统一为 Feather 图标集。
  • 界面与文案全量本地化。助手提示、导入附件、应用设置、采集结果、用量通知、平台管理、英文工作台翻译全部完成；支持账号语言偏好。
  • 通过对话链发布和编辑 UI；助手按阶段展示运行轨迹；邀请改为邮件直发 24 小时链接。
  • 采集（collection）工作流补全：外部 HTTP 源读取、Typesafe Jev 提供端点、通知独立重试。
  • 概览卡片显示应用使用统计；生产发布切换脚本。

2026-10-03 – 10-06

  • 受控 json-render 运行时。后端 harness 与 json-render 渲染运行时上线，草稿通过 harness 组合与校验。
  • 业务动作与工作流。通用事务性业务动作、输入声明校验、工作流状态机、受限外部连接器。
  • 后台任务接入共享 Runtime；发布只读公开应用页；Jev 决策改用固定版本评估器。
  • 修复：附件/外发迁移、自动化重试、AI 配额事务内预留、账号注销事务化等一大批稳定性问题。

2026-09-28 – 10-02

架构重构
  • 换到 Go + PocketBase。移除 Mongo/DSH 技术栈，应用数据与账号持久化到内嵌 PocketBase，服务器迁移为 Go 单二进制。
  • Agent 优先的工作台。重构为 Agent 驱动的应用运行时：版本化应用运行、界面草稿历史、兼容历史版本恢复、持久化私人对话。
  • 持久后台任务（Bun 运行时）；成员邀请与企业 fx 网关。

2026-08-21 – 09-03

起点
  • 项目启动。核心 API、MongoDB 运行时、引导工作区 UI 与本体（ontology）设计内核。
  • 内置 DeepSeek Harness Agent、MCP 会话与权限追踪、Agent 执行轨迹按会话索引。
  • 租户文件资产、备份恢复脚本、Docker 部署与 nginx 反代。

更早的每次代码变更见 GitHub 提交历史。
