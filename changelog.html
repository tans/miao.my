更新日志

记录 MIAO 应用的版本更新：新功能、改进与修复。只有 GitHub Release 才代表可下载交付；源码提交和现场部署不会被写成已发布版本。查看 English changelog 或 全部 Releases。

发布说明单体发布：Go binary + 嵌入式 UI + PocketBase migration。升级前先备份；生产切换由 PM2 管理，健康检查失败会回到上一个 binary。数据库不会自动回滚，恢复前请保留备份并在隔离环境演练。阅读运维文档 ↗

v0.0.1

2026-10-10已打包Release ↗Commit ↗
  • 首个打包版本。二进制包可从 GitHub Release 下载，安装无需 Go 工具链和 npm 依赖。SHA-256 以 Release 附件中的同名 .sha256 为准。
  • 本地 API 测试套件独立到 miao-test 仓库。

  • 界面：工作区侧栏更紧凑；小助手支持显示/隐藏切换。
  • 业务配置视图改为只读，精简只读设置加载。

2026-10-09

构建 3388d67源码记录现场验收待单独确认Commit ↗
  • 应用图标与版本切换。新增应用图标和本地图标选择器；应用运行时工具栏可直接切换版本。

2026-10-08

源码记录现场验收待单独确认

大版本日源码记录现场验收待单独确认
