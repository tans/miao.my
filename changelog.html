v0.0.1

2026-10-10已打包Release ↗Commit ↗
  • 首个打包版本。二进制包可从 GitHub Release 下载，安装无需 Go 工具链和 npm 依赖。SHA-256 以 Release 附件中的同名 .sha256 为准。
  • 本地 API 测试套件独立到 miao-test 仓库。
  • 修复：拒绝旧版 LLM 配置重置；恢复受控 LLM 决策提案。
  • 界面：工作区侧栏更紧凑；小助手支持显示/隐藏切换。
  • 业务配置视图改为只读，精简只读设置加载。

2026-10-09

构建 3388d67源码记录现场验收待单独确认Commit ↗
  • 应用图标与版本切换。新增应用图标和本地图标选择器；应用运行时工具栏可直接切换版本。
  • 自托管 daisyUI 与 Tailwind 浏览器资源，减少前端启动资源传输。
  • 发布对话式 UI 草稿无需二次确认；移除应用运行时下的草稿与版本历史区块。
  • 修复：表单去重并持久化运行指标、应用设置渲染、工作区选择器越界、助手加载与模型错误提示、清理失败的助手重试。
  • 禁用旧版 LLM Agent 流程；Jev 评估全部改用 Typesafe。

2026-10-08

源码记录现场验收待单独确认
  • 版本发布与 SSE 流式更新。支持发布应用变更并切换版本；助手和应用运行时更新改为 SSE 流式推送。

2026-10-07

大版本日源码记录现场验收待单独确认
  • 工作台全面成型。小助手固定为第三栏深色终端风格停靠列；工作区切换器改为下拉菜单；图标统一为 Feather 图标集。
  • 界面与文案全量本地化。助手提示、导入附件、应用设置、采集结果、用量通知、平台管理、英文工作台翻译全部完成；支持账号语言偏好。
  • 通过对话链发布和编辑 UI；助手按阶段展示运行轨迹；邀请改为邮件直发 24 小时链接。

  • 概览卡片显示应用使用统计；生产发布切换脚本。

2026-10-03 – 10-06
