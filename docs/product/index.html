MIAO 产品说明

MIAO 帮个人工作区的使用者搭建轻量内部数据应用：描述要管理的工作，创建数据表，再维护业务记录。

适合什么工作

当工作需要一张专用的数据表来记录、查询和整理信息时，可以用 MIAO 创建一个小型工具。例如跟进客户、维护项目清单或整理日常业务记录。

如何使用

  1. 创建应用，并用一句话说明它要解决的工作。
  2. 创建数据表和字段，定义要记录的信息。
  3. 浏览、添加和删除记录；也可以使用内置 AI 助手协助创建数据表和操作记录。

当前产品范围

  • 每个账号拥有自己的工作区。
  • 应用包含数据表和业务记录。
  • AI 助手运行在浏览器中，通过 MIAO 提供的工具操作当前应用数据。
  • 使用 AI 助手时，需要用户提供 Vercel AI Gateway Key；密钥仅保存在当前页面内存中，刷新后需重新输入。

当前限制

目前没有工作区邀请和成员角色；应用不会根据描述自动生成完整页面或业务流程。AI 助手需要支持 JavaScript Promise Integration（JSPI）的浏览器。官网与这份文档是静态信息页，不包含账号注册、工作区或后端 API。

产品能力说明依据当前代码与产品定义整理，功能范围可能随版本更新。
