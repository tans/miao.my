MIAO 产品说明

MIAO 是一个开源企业内部工作台，目标是让团队把日常流程、业务数据和 AI 助手放进可自托管、可扩展的工作环境。

产品方向

企业可以根据自己的流程创建内部应用，在工作台中组织数据，并让 AI 助手参与信息查询与整理。开源代码便于团队检查、部署和按需扩展。

为什么选择 MIAO

  • 内置 AI 助手：用自然语言描述需求，快速搭建企业内部应用。
  • 开源、自主部署：运行在企业自己的环境中，业务数据由企业管理。
  • 免平台年费：MIAO 软件不收年费，不依赖随使用规模上涨的平台订阅费。
  • 面向中小企业：轻量、简单、快速上线，从真实工作流程开始。

如何使用

  1. 创建应用，并用一句话说明它要解决的工作。
  2. 创建数据表和字段，定义要记录的信息。
  3. 浏览、添加和删除记录；也可以使用内置 AI 助手协助创建数据表和操作记录。

当前已实现

  • 每个账号拥有自己的工作区。
  • 应用包含数据表和业务记录。
  • AI 助手运行在浏览器中，通过 MIAO 提供的工具操作当前应用数据。
  • 使用 AI 助手时，需要用户提供 Vercel AI Gateway Key；密钥仅保存在当前页面内存中，刷新后需重新输入。

当前阶段与边界

“企业内部工作台”是 MIAO 的产品定位和发展方向。当前版本仍以个人工作区为基础，尚无工作区邀请、成员角色和团队共享；应用也不会根据描述自动生成完整页面或业务流程。AI 助手需要支持 JavaScript Promise Integration（JSPI）的浏览器。此 Vercel 站点只包含官网与文档，完整应用的 API 和 PocketBase 需要单独部署。

自托管不等于没有运行成本：企业仍需承担自己的服务器、域名，以及按需使用的 AI 服务费用；MIAO 本身不收平台年费。

产品能力说明依据当前代码与产品定义整理，功能范围可能随版本更新。
