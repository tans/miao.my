SELF-HOSTING · COSTS & DEPENDENCIES

部署前要准备什么，谁付费

MIAO 源码采用 Apache License 2.0，软件本身免费；但自托管时服务器、域名、备份、模型推理和邮件服务由部署方自行准备与付费。本页列出每项依赖的用途、责任方和未配置时的影响，全部结论可追溯到 LICENSE、运维手册或供应商官方页面（核对日期 2026-10-12）。本页不提供 MIAO 商业套餐或任何报价。

成本与服务依赖一览

项目用途与何时需要谁配置 / 谁付费计费与定价依据未配置时的影响
MIAO 软件许可始终需要；使用、修改、再分发（含商业产品）无需付费；部署方自行遵守许可与商标限制Apache License 2.0 ↗；TRADEMARKS.md ↗（名称、Logo、吉祥物不在许可范围内）无。开源不等于基础设施和模型推理免费
服务器与运行环境始终需要；单个 Go 进程（PM2），Linux/macOS x64/ARM64，运行已构建二进制不需要 Go 或 Node.js部署方配置并付费以所选云或物理服务器供应商为准无法安装运行
域名与 HTTPS 证书公网提供服务时需要；反向代理负责 HTTPS、域名和端口边界（默认监听 0.0.0.0:41874）部署方配置并付费以域名注册商和证书来源为准仅能内网或回环访问
数据存储与备份空间始终需要；pb_data/ 数据库与附件，备份默认写入数据目录下 backups/、保留 30 天；脚本不创建定时任务和异地副本部署方配置定时备份并付费以存储供应商为准故障或误操作后无法恢复；备份归档含生产数据，需按生产数据保护
LLM 生成模型小助手提案、界面草稿等开放式需求的结构化提案；在后台 /admin/ai 配置 provider、base_url 和密钥，密钥只存服务端平台管理员配置；费用按所选模型供应商由部署方承担以所选模型供应商的官方定价为准（本页不代报价格）依赖模型提案的对话式搭建、界面编辑和记录 AI 操作在创建请求前被拒绝
JEV 决策模型候选选择与决策校验（Typesafe Jev）；与 LLM 同在 /admin/ai 配置（kind=jev）平台管理员配置；费用同上。空间所有者可通过 PATCH /api/workspace/ai-budget 设置每日总量与 LLM/JEV 分类上限（0 表示不限制）以所选供应商官方定价为准；平台用量页是请求/token 统计，不是费用账单JEV 决策链及其覆盖的搭建、发布判断和业务动作不可用
邮件服务（Resend）注册邮箱验证和邀请邮件；在后台 /admin/settings 配置发件人与 Resend 密钥平台管理员配置；费用由部署方按 Resend 账单承担resend.com/pricing ↗（2026-10-12 核对，以供应商为准）无法开启“注册需验证邮箱”（开启前必须已保存有效邮件服务）；邀请邮件发不出，但仍始终返回可复制的邀请链接
定制部署（可选）不想自行运维时；首页“定制部署，联系客服”入口按咨询结果协商咨询报价不等于托管 SLA 或推理配额；本页不承诺任何价格不影响自行部署

未配置模型或 Jev 时，哪些流程受限

AI 未配置、停用或预算拦截都会在创建请求记录前拒绝，失败调用和连接检查也消耗预算：

  • 不依赖模型，配置好即可用：登录与权限、数据表和记录的手动管理、状态流、后台任务按既有授权执行、已发布公开页的字段读取。
  • 缺少 LLM 生成模型：小助手提案、界面草稿等开放式需求生成不可用。
  • 缺少 JEV 决策模型：候选选择与决策校验不可用；应用的对话式搭建、界面修改和公开发布判断（发布候选中的公开范围由 Jev 给出）无法推进。
  • 缺少邮件服务：注册验证和邀请邮件受影响，如上表。

部署前准备清单

  1. 服务器账号与目标环境（Linux/macOS x64/ARM64，PM2、curl、openssl）。
  2. 首个平台管理员邮箱，以及 MIAO_SETTINGS_ENCRYPTION_KEY 加密密钥（缺失时不能保存或读取服务端独立密钥；全新安装只需数据目录、端口、加密密钥、管理员邮箱四项）。
  3. 模型服务账号：LLM 与 JEV 各自的 provider、base_url 和 API 密钥；先设好工作区每日预算上限再放开使用。
  4. Resend 账号与已验证的发件人域名（需要注册验证或邀请邮件时）。
  5. 域名与 HTTPS 反向代理配置。
  6. 备份空间、定时任务与异地副本（脚本不代建），以及一位负责升级、恢复演练和服务可用性的运维负责人。

自托管者承担的运维责任

升级与回滚、备份与恢复验证、HTTPS 与服务可用性都由部署方承担。发布脚本在启动或健康检查失败时切回上一个 release，但数据库不会自动回滚；恢复前另存当前备份并在隔离环境演练。健康检查 200 不代表模型、邮件或生产域名已经验收。
